Summary notes on how LLMs are used as the reasoning core of autonomous agents.

Surveys agent architectures built around large language models, covering how
they plan, use tools, and maintain memory to accomplish multi-step tasks
without step-by-step human supervision.

- Core components: profiling, memory, planning, and action modules
- Planning strategies include reflection, task decomposition, and self-critique
- Tool use lets agents call external APIs, search, and code execution environments
